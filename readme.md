** Pointers and offsets are working for Rekordbox 7.0.2. ** 

WIP for a simple python script used to read information from all decks loaded in rekordbox (Title,Artist,Album).


In the future I will be adding a way to read the current tempo of the tracks playing, time remaining, etc. As it currently only fetches the initial values. 


My main goal for this project is to make a programm capable of reading all the relevant information and display it on a wesbite, external device with screen or setup a server from which the information can be fethced from. The final project will (hopefully) be built using a different language as Python does have its limitions.
